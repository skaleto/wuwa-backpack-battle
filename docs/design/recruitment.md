# V115 自由组合招募：当前实现规则

更新：2026-10-23。参数由当前运行代码导出到 [rules.json](rules.json)，下表对应本次实装。请从「开始挑战」进入新版；已有对局沿用原招募规则。

## 选择与招募

- 开局只选起点；所有武器、专武都可自由购买、使用和合成。
- 第 3、6 回合战斗结束、仍可继续本局时，自动打开免费三选一。
- 下列十二名队友共用候选池，只排除主角本人和已招募角色；不按属性、武器主人或原作搭档限制。
- 每次尽量呈现三个不同方向，并在可能时保证至少一个当前装备能触发的选择。候选保存后，重进游戏不会重抽。
- 第一位队友加入就有完整基础能力。第二位保留同样基础能力，并额外启用自己所属方向的满编能力；无需指定搭档、物品或移动星位。
- 招募后开放该队友的一小组特色商品，通用池保留。特色物品的使用和合成不检查队友资格。

## 队友基础能力

这里的「自然攻击」指物品自己的正常出手，不包含由队友派生的额外伤害；避免奖励反复触发自身。间隔为同一能力的最短触发间隔。

| 队友 | 方向 | 加入即生效 | 适用与取舍 |
| --- | --- | --- | --- |
| 琳奈 | 充能 | 武器和声骸各自然攻击一次，获得 2 充能；间隔 3 秒。 | 需要武器和攻击型声骸。 |
| 露帕 | 充能 | 累计 3 次武器自然攻击，获得 2 充能；间隔 3 秒。 | 高攻速、多武器更容易触发。 |
| 吟霖 | 冷却接力 | 累计 2 次武器自然攻击，推进剩余冷却最长的声骸 0.9 秒；间隔 3 秒。 | 需要有攻击冷却的声骸。 |
| 达妮娅 | 冷却接力 | 累计 2 次声骸自然攻击，推进剩余冷却最长的武器 0.9 秒；间隔 3 秒。 | 攻击型声骸越多，接力越频繁。 |
| 莫宁 | 耐力 | 每 4 秒回复 1 耐力。 | 耐力已满时不储存回复。 |
| 尤诺 | 耐力 | 实际累计消耗 4 耐力，回复 0.8 耐力；间隔 2 秒。 | 按实际消耗计数，低耗耐时触发较慢。 |
| 守岸人 | 生存 | 每 4 秒治疗 2，溢出治疗的 50% 转为护盾。 | 偏持续生存，不能立即抵消爆发。 |
| 坎特蕾拉 | 生存 | 累计 3 次声骸自然攻击，治疗 3，溢出治疗的 50% 转为护盾；间隔 3 秒。 | 需要攻击型声骸。 |
| 菲比 | 减益 | 累计 4 次武器自然攻击，给对方施加 1 光噪；间隔 6 秒。 | 光噪需要时间持续造成伤害。 |
| 穗穗 | 减益 | 累计 2 次武器自然攻击，给对方施加 2 霜渐；间隔 4 秒。 | 减速与冻结提供节奏优势，不直接增加伤害。 |
| 釉瑚 | 经济 | 加入时获得 2 金币。每回合首次合成，返还一件合资格的低阶材料。 | 返还品质不超过蓝色、售价不超过 6 的最低价普通材料。 |
| 灯灯 | 经济 | 加入时获得 2 金币。每回合多一次免费刷新。 | 收益用于后续购买，不直接增加战斗数值。 |

釉瑚返还条件：被本次合成真实消耗的普通功能材料，品质不超过蓝色、标价不超过 6 金币；排除武器、声骸、口袋。多个合资格材料时自动选择最低标价的一件，返还到储物箱，返还品购买成本为 0。无合资格材料的合成不占用本轮返还机会。

## 满编额外能力

由第 6 回合后招募的队友决定；第一位队友的基础能力继续保留。同方向队友可以同队，不要求固定人名组合。

| 第二位队友方向 | 满编能力 | 实际效果 |
| --- | --- | --- |
| 充能 | 蓄能追击 | 充能武器自然攻击额外造成 3 伤害；间隔 4 秒。 |
| 冷却接力 | 交错接力 | 武器和声骸各自然攻击一次，推进剩余冷却最长的武器 0.6 秒；间隔 3 秒。 |
| 耐力 | 耐力护航 | 实际累计消耗 6 耐力，获得 3 护盾；间隔 3 秒。 |
| 生存 | 守护反击 | 护盾实际累计抵挡 12 敌方伤害，回击 3 伤害；间隔 3 秒。 |
| 减益 | 印记追击 | 武器自然攻击已带光噪或霜渐的敌人时，额外造成 3 伤害；间隔 4 秒。 |
| 经济 | 同行工坊 | 满编时额外获得 3 金币。此后每回合首次合成返还 1 金币。 |

经济队友在第二次招募时共立即获得 5 金币（自身 2 + 满编 3）。灯灯使每轮合计有两次免费刷新；已使用的刷新次数不重置。满编经济的首次合成奖励与釉瑚返材可以同时触发，均每轮至多一次。

## 三个组合例子

| 起点与招募顺序 | 买什么、怎么受益 |
| --- | --- |
| 爱弥斯 → 露帕 → 尤诺 | 多武器增加露帕的充能触发；实际消耗耐力让尤诺回耐；满编后耗耐同时积累护盾。仍需考虑每把武器的耗耐和攻击间隔。 |
| 心 → 吟霖 → 坎特蕾拉 | 保留一把能正常出手的武器，并加入攻击型声骸；武器推动声骸冷却，声骸出手提供治疗。满编反击还需要真正能产盾并挡伤的物品。 |
| 琳奈 → 灯灯 → 釉瑚 | 更多免费刷新寻找合成分支；釉瑚返还低阶材料，满编每轮首次合成再得 1 金币。收益要花回装备，队友本身不凭空增加战斗伤害。 |

## 表现与兼容

招募沿用幕布展开、卡片自下而上显现、确认后溶解与归队动画。整备队伍页只展示已经获得的能力，不再弹出选物品、配对或移动星位步骤。

旧 V114／V113 对局和影像保留旧能力；新版与旧版战斗影像不会混配。旧局升级读取会先保留备份，不重算已经结束的战果。
