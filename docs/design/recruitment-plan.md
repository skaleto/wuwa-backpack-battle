# 五武器开局与自由招募：已确认设计

确认日期：2026-10-23。

状态：用户确认后已按此框架实现 V115。本文保留框架确认时的讨论范围；具体技能、数值及当前状态以 [V115 规则](../recruitment-v115/rules.md) 和 [验证记录](../recruitment-v115/validation.md) 为准。旧局按旧招募版本继续。

## 1. 设计目标

角色提供起点，物品与局内选择决定路线。招募让玩家获得新的购买、摆放、合成及战斗组合机会；选择队友以后，通过现有玩法自然生效，不另设技能目标配置流程。

用户确认要点：

- 主角采用爱弥斯、心、景燃、赞妮、琳奈，五种武器各一位。
- 不按鸣潮原作配队设置属性门槛、角色绑定或队友名单；允许自由组合。
- 每名队友独立有效，相近定位存在可替代角色，替代者强度差距不能明显过大。
- 第3、第6回合免费随机三选一的节点保留。

武器类型仅用于初始配置。五位主角均可在局内自由购买、合成、使用和混用五种武器及专武。不得恢复主副武器折扣、指定主人资格，或按主角封闭某条流派。

初始武器的具体物品、补给、角色开局效果及其数值尚需设计；不能把先前主角的被动按头像直接套用并宣称已经校准。该名单替代上一轮的六名开局角色方案，不包含删除其他角色素材或存档的操作。

## 3. 招募与候选池

| 项目 | 确认规则 |
| --- | --- |
| 第一次招募 | 第3回合结束且对局继续；免费随机三选一，形成主角＋一名队友 |
| 第二次招募 | 第6回合结束且对局继续；免费随机三选一，形成主角＋两名队友 |
| 名单范围 | 所有主角共用已设计的队友候选池 |
| 排除项 | 当前主角、已经入队的角色 |
| 角色属性 | 不作为招募、物品使用或组合资格的门槛 |
| 二／三号位 | 仅表示加入顺序，同一队友的基础能力保持一致 |
| 商店 | 公共池保留；入队后增加该队友的一小组特色商品 |
| 使用与合成 | 合法获得的物品完整生效，配方不重新检查队友或专武主人 |

“共用候选池”不表示未经设计的全部资料角色自动入池。首批队友完整名单、抽取权重、同能力候选的区分与可用性保障，需要在后续技能表中明确；不得以此重建指定主角的白名单。

现有节点保存、重启恢复相同候选、重复提交防护和锁定商品保持等行为，后续实现继续遵守项目既有边界。

## 4. 独立能力与替代关系

独立能力不依赖指定的另一名队友或稀有专武。普通武器、声骸、补给、实际攻击、治疗、挡伤、耐力消耗或减益事件，可以作为条件。招募仍然需要对后续购买与摆放产生影响。

能力必须说清触发条件、实际受益对象、上限或间隔。战斗自动执行，不让用户额外指定两把武器、移动星位、绑定治疗与护盾物品或设置技能目标。

同定位替代者通过节奏和构筑适配区分。例如稳定回耐与随实际消耗返还耐力，都可以承担耐力支持；不能有一个角色独占组合启动资格，另一个只能提供微弱补偿。

上述只是设计示例，不是已确认的角色技能或数值。先前列出的琳奈、露帕、吟霖、达妮娅等具体效果仍属草案，需要按自由组合框架重新整理。

## 5. 两人到三人的成长

第3回合获得第一名队友的完整独立能力与特色供给，能够立即围绕普通物品形成新的选择。

第6回合获得第二名队友的完整独立能力、特色供给和额外组合成长。未满编不削减已有队友能力；基础技能不因第3或第6回合入队而改变。满编强化与基础技能需明确区分。

满编效果围绕实际玩法条件设计，可由物品提供所需条件，不绑定固定姓名或鸣潮原作队伍。例如“实际挡伤累计达到阈值，获得充能”，其护盾来源可以是物品或队友。这仅演示无身份绑定的规则，具体效果、阈值与触发范围尚未定稿。

不得用角色姓名改成隐藏标签的方式恢复唯一队友组合；新增反馈必须对应真实收益。额外攻击、治疗、回耐等派生效果的触发边界要明确，防止互相重复计数形成无限循环。

## 6. 继续保留的体验与边界

- 整备中的操作仍为选购、摆放、旋转、合成、收纳；战斗全自动。
- 保留已批准的 Q 版旅行邀请卡、幕布展开、卡片上浮、确认后溶解和头像归队方向。本次没有批准新的视觉改版。
- 展示以实际物品、星位、触发反馈及简短效果描述解释结果，不增加常驻教学段落。
- 招募扩大特色供给，不夺走公共商品、既有配方或已持有物品的效果。
- 武器、声骸和物品合成仍是战力成长主体；队友不能包办输出、回耐与生存。
- 玩家与对手遵守相同规则；保护真实玩家存档，验证使用独立数据路径。

## 8. 后续验证要求

1. 五种武器各有一位开局角色，所有主角仍能购买、使用与合成其他武器。
2. 主角变化不封闭候选角色或原有配方；同一队友的基础能力与加入位置无关。
3. 没有指定搭档时，队友能够在普通、合理投入的背包中提供真实收益；不需要额外技能配置界面。
4. 第3回合能力可以独立运行；第6回合新增组合收益不吞掉已有能力，所需条件允许通过物品完成。
5. 相近定位替换后仍能运行主要组合。在相同投入、不同对手、不同阶段下测量收益与整局表现，不通过隐藏补偿强行抹平差异。
6. 战斗与经济角色都检查招募当轮的可兑现收益、后续回本和转型空间；具体平衡阈值另行确定。
7. 特效、头像反馈和战报只记录实际发生的效果；额外触发不递归套利。
