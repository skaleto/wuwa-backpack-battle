# 发布隐私约束

开发者公开身份只使用 GitHub 账号名 `Skaleto`。提交作者、提交者和标签使用该账号与 GitHub noreply 邮箱；不得使用真实姓名或私人、工作邮箱。

源码、历史提交、发布说明、素材元数据、截图和安装包不得包含开发者本机目录、设备/局域网标识、代理会话标识、凭据。素材来源登记仓库相对路径或公开来源链接；私有外部来源只标记 `private-source`。第三方许可证要求的作者署名照常保留。

发布前运行：

```bash
python3 tools/privacy.py
python3 -m unittest discover -s tests -p test_privacy.py -v
python3 tools/check.py --jobs 2
```

`tools/build.py` 的暂存入口也会扫描运行文件。目录外的凭据、私有报告和备份不得加入发布清单。发布包须解包检查资源与元数据，不能仅搜索压缩文件外层字节。历史分支、标签和旧下载版本也在清理范围内。

素材来源曾参与已发布目录的摘要。`data/compat/privacy-fingerprints.json` 只将已核验脱敏文本的精确 SHA-256 对应到原发布摘要，保留旧存档和联机池身份。任何其他文本变化仍产生新摘要。不得增加映射以掩盖规则、数值或战果变更。

清理覆盖维护者可管理的源码与下载入口。已被第三方下载、克隆、分叉或缓存的旧副本无法通过改写仓库自动收回；托管平台仍可按旧提交 ID 暂存不可达对象，必要时需向平台申请敏感数据清除。
