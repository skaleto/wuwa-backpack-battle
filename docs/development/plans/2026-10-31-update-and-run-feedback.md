# 更新提示、结束本局与胜负反馈

- 已有启动后台检查继续使用；主界面安全空闲时发现新版主动打开一次更新页，返回按钮是“稍后”，不打断拖动、战斗或其他弹层。
- 菜单和更新页提供“结束本局”。确认展示模式和当前进度，取消保留；确认后应用层先保留已完成战斗记录，再由存储层核对活动存档、备份并原子移走当前 run.json，最后清空活动状态。保留历史、身份、偏好与另一模式，不伪造失败或胜场。
- 更新页列出尚未结束的模式，可以分别结束。所有活动局结束后允许重启，基础更新器与已有签名信任配置保持不变。
- HUD 用 8 个奖杯、4 颗红心和数值表达进度，回合数独立显示。胜利增加一个奖杯的弹出与飞入动画；失败消失一颗红心，裂成两片后落下，槽位灰显。平局沿用现有扣生命规则，清楚显示实际变化。
- 结算动画只读取现有结果投影，不在绘图里发奖。点继续仍走现有单次结算，跳过、重载、回放都不能重复增减。
- 验证：启动提示一次性；取消/确认/保存失败/过期/两模式隔离；胜负和终局数值投影；隐藏原生截图；完整回归与更新通道验包。
