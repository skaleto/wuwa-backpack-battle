# V2：口袋、回收箱和战斗反馈

本轮改动纳入 V2 / 0.2.0；发布与兼容边界见 [发行说明](../release/v2.md)。

| 口袋 | 新开局效果 | 条件 |
| --- | --- | --- |
| 单格 | 开场护盾 +3 | 该格有物品 |
| 双格 | 冷却缩短 6% | 有冷却的物品接触；补给与材料除外，沿用原加速袋范围 |
| 长 L | 武器出手伤害 +6% | 接触至少一格 |
| 反向长 L | 声骸出手伤害 +10% | 接触至少一格 |

原六格基础袋继续只提供容量。未调整售价、形状、商店概率和物品数值。当前规则下同类加成取最大值，与袋子遍历顺序无关；不同类型可组合。空单格袋不提供护盾。旧规则委托冻结实现，新局通过 `pocket_version=143` 明确启用；快照、存档、对手和池身份携带该字段，旧快照与历史回放不重写。

商店按住小口袋沿用货架固定格距，只有轻微抬起，不撑满缩略图。回收箱位于商店底部，箱体和箱盖来自独立图层；仅已拥有物品可开盖，显示真实回收价，放下走原出售事务。原有袋子出售确认保留，避免意外挤出整袋物品。

奖杯弹出与心碎主图放大，奖杯飞入顶部计数；结果页保留大图及本次增减。动画不结算数值。

角色展示略向上留位，生命、体力和增减益各自独立。增益为薄荷底、减益为粉色底，图标配短名称和层数；悬停显示简短含义及剩余秒数。绘制与命中使用同一组坐标，背包布局不变。

验证入口：`test_polish_v143` 检查实际出售、缩略图路径、口袋实战加成与旧规则、轮转接触、同类取强、快照与池隔离、状态栏边界。`tests/visual/polish_v143_preview.gd` 使用独立 QA 存档、最小化不可聚焦主窗口和 SubViewport 检查实际画面。全套测试与三端包结果以本次执行日志为准。

本轮验证：全套 170 组回归首轮 168 组通过，两组旧测试对当前应用/旧口袋显示缺少显式版本上下文；补上上下文、保留原断言后全部复测通过。新增测试覆盖原出售事务、真实开场护盾、旋转接触、同类取强、旧/新快照编解码及模式隔离。隐藏原生画布检查了回收箱开盖、双侧五种状态、悬停含义及奖杯/心碎画面。三端导出分别验证原始资源，Mac 包另有原生渲染与启动检查；Windows 和 Web 未在真实设备上重玩。
