# 简洁伙伴卡与随机货架

日期：2026-10-30。用户确认招募方案 01；同时完成其前述头像、一格袋比例、随机刷新和在线寻找对手界面修改。

## 实现

- 招募使用独立生成卡底，真实角色、名字、能力、物品分层，双倍离屏分辨率；保留幕布、错峰浮现、选中和入队溶解。按钮绘制与命中矩形一致。
- 队友头像在头像框内居中，不继承角色全身底部对齐。原图自身的角色姿势保留。
- 商店口袋每格最多 36 逻辑像素；一格 36×36、两格 72×36、四方格 72×72，长 L 72×108。其余物品不改缩放。
- 寻找对手用玩家头像与待匹配卡片、动态圆点；视图只收角色 ID 和时间，不控制网络，不伪造百分比。
- 六个货架位置都使用随机类别，武器 28%、声骸 22%、普通物品 35%、口袋 15%。商品总数仍为六，类别数量不再固定。没有可用商品的类别会重新分配其权重。
- 每类别沿用既有回合品质曲线、族群权重、稀缺催化剂权重。原第 4/5 位的星位伙伴/缺材加权保留，属于概率辅助；不固定商品类别。招募后的单次特色商品和已有锁定保留。
- 原隐藏假定“只有第六位是袋子”的校验、快捷键替换、事务、练习对手采购改为读取商品真实类别。替换计划带精确槽位，并通过既有原子事务提交。
