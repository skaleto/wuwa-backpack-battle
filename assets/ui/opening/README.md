# 开场独立图层

`opening.png`为内置imagegen生成的RGBA图集，原文件直接复制，没有重新压缩、裁掉边缘或重新绘画。源路径、SHA和各组件的source rect在上一级manifest中。

最终提示：保持Q版旅行收纳的淡紫、薄荷、奶油和暖金手绘风格，包含宽椭圆绒布展示毯、留出最大头像空间的圆形徽章、可从顶部悬挂的四角星与月亮吊饰；全透明背景、无文字，各组件留透明间隔，便于独立动画。第二次使用内置编辑能力仅调整图集间距，避免毯子碰到头像框顶端。

组件在原生Godot中分层使用，吊饰以顶部为转轴，角色原画和实时文字保持独立。运行时只读取对应矩形，不修改图集或角色图像。
