# 应用图标

统一图案：游戏现有 Q 版爱弥斯头像。保留粉发、金色眼睛、蓝白羽饰与黑白服饰，浅青背景，背包作为小型辅助元素。无文字，以角色辨识度优先。

- `app-icon.png`：1024×1024，不透明主图；项目窗口、Web 和 iOS 导出的来源。
- `app-icon.ico`：Windows 文件及任务栏图标，包含 16/20/24/32/40/48/64/128/256 像素。
- `app-icon.icns`：macOS 应用及 Dock 图标，含 Retina 尺寸，最大 1024 像素。

插画由内置 imagegen 参考 `assets/characters/role_1210.png` 生成。提示词：保持原游戏 Q 版爱弥斯身份与画风，粉色卷发马尾、金眼、蓝白羽饰、黑白服饰；头肩近景、明快表情、浅青不透明背景，小型淡紫布袋仅作辅助；适合桌面小图标，不加文字、复杂边框、细碎粒子或塑料高光。

`python3 tools/assets/build_app_icons.py` 在 macOS 上从已批准 PNG 转换 ICO/ICNS。仅转换尺寸、格式并清除非必要元数据，不重新绘制插画。其他构建主机直接使用已提交文件。

桌面文件图标属于 EXE / APP，必须随完整客户端更新。此次修改了项目图标配置，不能作为旧 desktop-v141 基线的资源热补丁发布；保留现有更新构建校验，完整版本发布时建立新的基线。已发布的旧包与旧更新清单不就地覆盖。


当前角色版图标已进入 `releases/V2` 的三端候选包；Mac 完整程序启动、包内整备/战斗/结算画面及签名验证通过。Windows 已完成导出和包内资源检查，本轮未进行 Windows 真机测试。
